## RN-able 2

# Django project supporting informatics analyses


Libraries to manage with poetry:
- python-decouple
- psycopg2-binary
- postgres

# RN-able 2 Setup Instructions

## Prerequisites

- Python 3.8+
- PostgreSQL 12+

## Installation

### 1. Clone Repository
```bash
git clone https://github.com/rbednarek/rnable.git
cd rnable
```

### 2. Setup
```bash
make setup-all
```
